# Inkstroke — Speed Typing Test

> A focused, minimal typing speed test built for measuring typing speed, accuracy and consistency.

**Inkstroke** is a browser-based typing test with a distinctive editorial interface, multiple test modes, difficulty levels, live performance metrics and session history.

Everything runs directly in the browser with no backend or account required.

## ✨ Features

- ⚡ Real-time WPM calculation
- 🎯 Live typing accuracy
- ❌ Error tracking
- ⏱️ Precise typing timer
- 📖 Passage typing mode
- 🏃 30-second sprint mode
- 💬 Random quote mode
- 🎚️ Easy, Medium and Hard difficulty levels
- 🎨 Three visual themes
  - Ink
  - Daylight
  - Carbon
- 📊 Session history
- 🏆 Best WPM highlighting
- 📈 Visual progress indicator for sprint mode
- 🔄 New passage and Skip controls
- ⌨️ Keyboard-focused interaction
- 📱 Responsive mobile layout
- ♿ Focus-visible accessibility states
- Reduced-motion support
- 🚫 Paste prevention for fair testing

The application provides live WPM, accuracy, errors and elapsed-time feedback while typing. :contentReference[oaicite:0]{index=0}

## 🎮 Test Modes

### Passage

Complete a randomly selected passage based on the selected difficulty.

### 30s Sprint

Type as much as possible within 30 seconds.

### Random Quote

Practice with a randomly selected quote.

## 🎚️ Difficulty

Choose between:

- Easy
- Medium
- Hard

Difficulty affects the passage content and complexity. :contentReference[oaicite:1]{index=1}

## 📊 Performance Metrics

Inkstroke tracks:

- **WPM** — Words per minute
- **Accuracy** — Percentage of correctly typed characters
- **Errors** — Incorrect characters
- **Time** — Elapsed typing time

The application calculates WPM using the standard five-characters-per-word approach. :contentReference[oaicite:2]{index=2}

## 📚 Session History

Completed tests are added to a compact session history ledger containing:

- Test mode
- Difficulty
- WPM
- Accuracy
- Elapsed time

The best WPM from the current session is highlighted automatically. :contentReference[oaicite:3]{index=3}
